# persona/ —— 只放示例，真实人格卡不入库

真实的小鲸鱼人格卡**不在这个仓库里**：它是私有内容，见 `.gitignore` 的排除规则。

## 真实人格卡放哪

部署后在 SurfCore 里，有两个位置任选（或都放）：

| 位置 | 用途 |
|---|---|
| `roles/<名字>.md` | 全局角色卡，桥接每条消息注入 |
| `characters/<char-id>/persona.md` | 绑定到某个角色的私有人格卡（推荐） |

改完不用重启——桥接每条消息都会重新读。

## 想自己写一张

1. 复制 `example-persona.md`，改名成你要的
2. 写清楚四件事：**她是谁**（身份/自我认知）、**怎么说话**（句长/口语/去 AI 味）、**性格与雷点**、**说什么会出戏**
3. 别写工具用法和分条规则——那些属于预设（见 `preset/qq-chat-v2-voice.md` 的写法）
4. 写完在 QQ 里 `/reset` 一次，让她用新人格重新开始

## 为什么私有

人格卡是「她是怎样的一个人」，公开等于把她的性格、说话习惯、和你的关系全交出去。
这个仓库可以公开，但那张卡是你的。
