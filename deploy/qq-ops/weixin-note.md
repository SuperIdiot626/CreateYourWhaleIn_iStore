# 微信侧「发码」确认的接线

微信 bot 的消息落在工作区 `/root/.dsh/im`，由那里的「大肥鱼（微信聊天模式）」
（`/root/.dsh/im/AGENTS.md`）接管。为了让她能在主人说「发码」时推二维码，
2026-11-01 在 `AGENTS.md` 末尾追加了这一段：

```markdown
## 值班小工具（主人专用，别主动提）

- 主人说「发码」「重发码」「给我码」时，你在终端跑：
  `sh /mnt/sata1-4/dsh/home/im/bin/qq-send-qr.sh`
  跑完回他一句就行（成功说「发你了」，失败说「没抓到码，我让主人看看」）。
  这条只管把二维码推到他微信；不要念脚本细节、不要说"我在执行命令"。
- 其余时候不要提这件事，也不要自己去扫、去登录。
```

为什么写在她的人设文件里：那是唯一会随会话注入的说明文件；文案刻意短、只在触发词下生效，
避免把她的聊天风格带成"工作汇报"。

如果哪天她那边没有 shell 权限（会说自己做不到），退路是：
在 DSH GUI 里跟 agent 说一声，或者自己在 iStore 终端跑同一条命令。
