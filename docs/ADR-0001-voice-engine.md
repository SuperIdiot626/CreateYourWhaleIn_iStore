# ADR-0001：语音引擎选 Edge TTS

- 状态：已采纳（2026-10-30）
- 决策者：项目主人 + 实施者

## 背景

SurfCore 的语音子系统要求一个 voxd 契约的 HTTP 服务。官方提供两个包：

- 本地包：GPT-SoVITS，**需要 NVIDIA 6GB+**
- 云端包：火山引擎复刻音色，**需要 AppID + Access Key + 复刻音色 ID**

部署主机是一台低功耗 x86（Intel N3520，4 核，无独显，3.9GB 内存）。

## 选项

| 方案 | 成本 | 延迟 | 硬件要求 | 音色 |
|---|---|---|---|---|
| A. 本地 GPT-SoVITS | 免费 | CPU 上几十秒 | 6GB+ 显存 | 可定制 |
| B. 火山大模型 TTS | 约 5 元/万字符 | 首包 0.3s | 无 | 最好 |
| C. **Edge TTS（选中）** | **免费** | 首包 1.5~2.5s | 无 | 中等 |
| D. 阿里 CosyVoice | 约 2 元/万字符 | 首包 0.5s | 无 | 好 |

## 决定

选 **C（Edge TTS）** 作为 v0.1.0 默认引擎。

理由：

1. **零成本、零硬件**：N3520 没有独显，A 不现实；B/D 要先申请密钥、按量付费，验证阶段没必要。
2. **契约隔离**：引擎只是实现 `POST /v1/speak/file` 的壳，以后换 B/D 只换壳，桥接零改动。
3. **够用**：语音条是 2~10 秒的短句，Edge 的自然度足够；QQ 还会再压一次 SILK，音质溢价被削。

## 代价

- 依赖微软服务：没有 SLA，可能限流/变接口。挂了的表现是桥接 502 → 她改打字，不会静默假装。
- 音色一般（`XiaoyiNeural`）。想更好听：换 B（火山）或本地 A（有显卡时）。

## 后续

- 若语音量上来（>100 条/天），费用可忽略，届时可切火山换更好韵律。
- 已把引擎做成可替换：`docs/voice.md § 换引擎怎么换`。
